ANU SPENDING TRACKER - MOBILE PWA

1. Put this folder on an HTTPS website (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open index.html through that HTTPS website on the phone.
3. In Chrome on Android: menu -> Add to Home screen / Install app.
4. The tracker keeps its local data in the browser and can sync to the Google Apps Script URL already configured in the tracker.
5. Do NOT open index.html directly as a file:// URL if you want PWA installation/offline service-worker support.
